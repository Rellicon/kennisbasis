# Vault

Dit is het notitieboek van je AI-assistent: wat die over jou, je werk en je projecten weet. Jij mag erin lezen en schrijven, maar de assistent houdt het bij. Het is gewone tekst, dus het werkt met Claude, ChatGPT, Gemini en Mistral.

Begin altijd hier. Elke map heeft een eigen overzichtsnotitie met dezelfde naam als de map. Volg de links, raad geen paden.

| Map | Wat staat erin |
|---|---|
| [[Over mij/Over mij\|Over mij]] | Wie je bent, wat je doet, hoe je wilt dat je AI-assistent werkt |
| [[Projecten/Projecten\|Projecten]] | Een overzichtsnotitie per project of onderwerp, met de stand en de besluiten |
| [[Kennis/Kennis\|Kennis]] | Losse kennis: begrippen, personen, hoe iets werkt |
| [[Sessies/Sessies\|Sessies]] | Per opgeslagen sessie een korte notitie: wat er veranderde en wat de volgende stap is |
| `_Onderhoud` | Rapport van de wekelijkse controle |
| `_Prullenbak` | Wat weg mag. De assistent gooit nooit iets echt weg |
